MCP가 뭔가요?

MCP(Model Context Protocol)는 AI 에이전트가 외부 도구에 접근할 수 있게 해주는 개방형 표준이에요. 힉스필드 MCP를 클로드에 한 번 연결해두면 — 채팅창 안에서 이미지 생성, 영상 제작, 캐릭터 학습, 이전 생성 기록 활용까지 한 번에 처리할 수 있어요.

어떤 플랫폼에서 쓸 수 있어요?

Claude (웹/데스크탑), Claude Code, Perplexity, Cursor, OpenClaw, Hermes Agent, NemoClaw — MCP를 지원하는 모든 AI 에이전트에서 동일하게 작동해요.

2단계 — 이미지 만들기

어떤 이미지를 만들고 싶은지 한 줄로 던지면 돼요. 클로드가 알아서 적절한 모델(Nano Banana, Soul 2.0 등)을 골라서 1~2분 안에 결과를 보내줘요.
힉스필드로 노을 진 한강 산책하는 사람 이미지 만들어줘 힉스필드로 카페 인테리어 콘셉트 이미지 한 장 뽑아줘 힉스필드로 인스타그램 콘텐츠 표지 이미지 만들어줘. 분위기는 미니멀하게

헷갈릴 때 도움 되는 한 줄

어떤 모델 써야 할지 모르겠다 → '이런 콘텐츠 만들 건데 어떤 모델 추천해?'
쓸 수 있는 모델 종류부터 보고 싶다 → '힉스필드에서 쓸 수 있는 영상 모델 보여줘'
결과가 마음에 안 든다 → '좀 더 [밝게/시네마틱하게/실사처럼] 다시 만들어줘'
비율을 정하고 싶다 → 끝에 '세로 9:16으로' / '정사각형 1:1로' / '3:4로' 추가

진짜 처음이라면 이 한 줄로 시작 추천

클로드가 모델 목록 + 잔액을 한꺼번에 정리해줘서 '아, 이런 게 가능하구나' 감이 잡혀요.
힉스필드 MCP에서 쓸 수 있는 이미지·영상 모델 한 번 보여줘. 그리고 내 크레딧도 같이 알려줘.
이 한 줄로 시작하고, 그다음부터는 만들고 싶은 걸 자연어로 던지기만 하면 끝이에요. 이제 왕복 지옥 그만하고 클로드 안에서 다~ 해보세요.
