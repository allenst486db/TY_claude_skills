De novo 전사체 분석 가이드 — 분석 방향 및 Assembly Group 설정

De novo Transcriptome · Non-genome guided

분석 방향 결정과 Assembly Group 설정 가이드

De novo 분석은 조립(Assembly)에 어떤 샘플을 넣느냐가 전체 분석의 기준 서열을 결정합니다. 기준이 달라지면 결과를 비교할 수 없으므로, 데이터 생산 전에 방향을 확정해야 합니다.

1

First Principle

모든 판단의 기준 — Contig set

De novo 분석은 참조 유전체가 없으므로, 입력된 read를 조립해 가상의 참조 서열인 Contig set(Trinity.fasta)을 자체적으로 구축합니다. 발현량(Read count·TPM)은 이 Contig set을 좌표계로 삼아 계산된 값입니다. 따라서 좌표계가 다르면 값을 나란히 놓을 수 없습니다.

용어 정리 — 반드시 구분

Assembly group = 조립(Assembly)에 참여하는 샘플. 기준 서열(Contig set)을 만드는 재료입니다.

정량 대상 샘플 = 만들어진 Contig set에 매핑되어 발현량이 계산되는 샘플. Assembly group에 포함되지 않아도 정량 대상이 될 수 있습니다.

핵심 원칙

함께 DEG 분석할 샘플은 반드시 동일한 Contig set을 기준으로 정량되어야 합니다. (＝ 반드시 하나의 분석 건으로 함께 진행)

동일한 샘플군으로 재조립하더라도 clustering 과정의 난수(random) 요소로 Contig set이 미세하게 달라지므로, "나중에 똑같이 다시 만들면 된다"는 성립하지 않습니다.

2

Decision

분석 방향 결정 흐름

Reference 보유 여부와 기존 분석 결과 유무에 따라 [A] Assemble부터 진행 또는 [B] Assemble 결과 재활용으로 나뉩니다.

A-1

Assembly group = 모든 샘플

전체 DEG 가능

비교 대상 전체 샘플을 하나의 assembly group으로 지정해 단일 통합 Contig set을 만들고, 모든 샘플을 여기에 정량합니다.

특성

  • 해당 집단 전체에 대한 model 서열을 build할 수 있음
  • 집단의 전체적인 특성을 가장 잘 반영 — 공통 특성 분석에 유리
  • 주의 — 샘플 간 특성 차이가 크면 공유되는 유사 서열이 적어 clustering이 잘 되지 않고, assemble quality가 크게 저하될 수 있음 (예: metagenome)

품질 판단 지표 — contig 개수 폭증, 그리고 N50과 평균 길이의 큰 편차(짧은 contig가 대량 생성됨)

추천 상황

전체 샘플 간 DEG 분석이 필요한 경우 — 가장 표준적이고 권장되는 설정입니다.

A-2

Assembly group = 일부 샘플만 지정

전체 DEG 가능 특이 서열 누락

대표성 있는 샘플만 조립에 참여시켜 기준 서열을 만들고, 나머지 샘플은 그 Contig set에 매핑하여 정량합니다. 전반적인 이론은 A-1과 동일합니다.

  • Assembly group에 포함되지 않은 샘플도 정량 대상에는 포함되므로 DEG 분석은 정상 수행됨
  • 단, assembly group에 지정되지 않은 샘플에서 특이적으로 나타나는 서열은 조립되지 않아 누락됨
추천 상황

Control 샘플이 명확한 경우, 또는 특성을 대표하는 집단이 있어 해당 샘플군만 reference처럼 활용하고 싶은 경우

적용 예시

예시 1
바이러스 감염 / 비감염 샘플 중 비감염 샘플만 assembly group으로 지정 — 정상 상태를 기준 서열로 삼음
예시 2
식물 잎·줄기·뿌리 3반복(총 9샘플) 중 각 조직에서 1개씩 선발한 3샘플을 하나의 assembly group으로 지정 — 조직 특성을 고루 반영하면서 조립 부담을 낮춤
예시 3
같은 9샘플에서 assembly group을 조직별로 3개로 분리 지정 — 조직별 특이 서열 확보에는 유리하나, Contig set이 3개로 나뉘어 조직 간 DEG 비교는 불가
A-3

각 샘플별로 Assemble 진행

샘플 간 DEG 불가

샘플마다 독립적으로 조립하여 샘플 개수만큼의 Contig set을 생성합니다. 각 샘플에 특이적인 model 서열을 얻는 것이 목적입니다.

반드시 확인

이 방식은 샘플마다 기준 서열이 달라지므로 샘플 간 발현량 비교 및 DEG 분석이 원천적으로 불가능합니다. DEG가 목적이라면 A-1 또는 A-2를 선택해야 합니다.

  • 각 샘플에 특이적인 model 서열을 build할 수 있음
  • 샘플별 조립 결과를 독립적으로 확인·활용해야 하는 목적에 적합
추천 상황

샘플별 특성이 크게 다른 경우, 또는 각 샘플별로 나누어 결과를 확인해야 하는 경우

적용 예시

예시 1
각 샘플에 존재할 것으로 예상되는 virus 서열을 개별 탐색하고 싶은 경우
4

Category B

[B] Assemble 결과를 재활용하는 경우

기존 조립 결과(Contig set)와 annotation을 그대로 고정하고, 각 샘플의 quantification(expression profiling) 과정만 다시 진행합니다. 조립·annotation을 재수행하지 않으므로 분석 시간이 크게 단축됩니다.

특성

  • assemble·annotation 재진행 불필요 — 분석 시간이 크게 단축됨
  • 기존 결과물을 이용해 각 샘플별 quantification(＝expression profiling)만 진행
  • Contig set이 고정되므로 샘플군이 추가·변경되어도 DEG 분석 가능
  • 전제 조건 — 기존에 진행한 분석 결과의 전체 directory가 온전히 보존되어 있어야 진행 가능
  • 새로 추가된 샘플군에서만 특이적으로 발현되는 contig는 누락됨
  • 새 샘플이 기존 조립에 없는 서열을 많이 가질 경우 mapping rate가 저하될 수 있으므로 정량 신뢰도 QC 확인 필요
추천 상황

Contig set을 고정하고 싶은 경우, 기존 결과와의 통일성이 필요한 경우

동일 샘플군으로 재조립해도 난수 요소로 Contig set이 달라지므로, 재현성·일관성 확보에는 이 방식이 유일한 선택입니다.

Checklist

분석 요청 전 확인 사항

✓
비교(DEG)할 샘플을 모두 확정했는가 — 함께 비교할 샘플은 반드시 하나의 분석 건으로 함께 요청해야 합니다. 나중에 추가하면 [B] 방식 외에는 전체 재분석이 필요합니다.
✓
Reference 보유 여부를 확인했는가 — genome fasta와 gene annotation(gff/gff3) 중 하나라도 없으면 de novo로 진행합니다.
✓
Assembly group을 어떻게 설정할지 정했는가 — 전체(A-1) / 일부(A-2) / 샘플별(A-3). DEG가 목적이면 A-3는 선택할 수 없습니다.
✓
샘플 간 이질성이 큰가 — metagenome 등 특성 차이가 큰 샘플군은 조립 품질 저하가 예상되므로 사전 협의가 필요합니다.
✓
기존 분석 결과 디렉토리가 보존되어 있는가 — [B] 재활용 방식은 결과 전체 디렉토리가 있어야만 진행 가능합니다.
Trinity 기반 de novo 파이프라인 흐름(reads → assembly → contig set → alignment → quantification)을 기준으로 작성되었습니다. Assembly group 설정은 데이터 생산 전 확정을 권장합니다.
