# 목차(TOC) + 코드 복사 버튼

`assets/template.html`에 기본 내장된 두 기능. **본문 작성자가 손댈 부분은 없다** —
표준 마크업 규칙(섹션 구조, `termwin` 사용법)만 지키면 페이지 로드 시 자동으로
생성된다. 이 문서는 동작 원리와, 망가뜨리지 않는 법을 설명한다.

## 1. 목차(TOC) 사이드바

### 동작 방식

문서 하단의 `<script>`가 `.content > section` 전부를 스캔해서 목차를 만든다.

- **1단계 항목** = 각 섹션의 `<h2>`. 섹션에 `id`가 없으면 `sec-1`, `sec-2`…로
  자동 부여한다. `.sec-num`이 있으면 그 번호를 칩으로 보여준다.
- **2단계 항목(접기/펼치기)** = 그 섹션 안의 `<h3>` 전부(예: `.method` 블록의
  툴 이름). `<h3>`가 있는 섹션에만 펼침 화살표(▸)가 붙는다. `<h3>`가 없으면
  1단계 항목만 있는 채로 끝 — 정상이다.
- 클릭하면 `scrollIntoView({behavior:'smooth'})`로 이동하고, 모바일/좁은
  화면에서는 목차를 자동으로 닫는다.
- `IntersectionObserver`로 현재 보고 있는 섹션을 목차에서 강조(scroll-spy)한다.

### 반응형 동작

| 화면 폭 | 기본 상태 | 형태 |
|---|---|---|
| ≥ 1181px (데스크톱) | **펼침(open)** | 본문 왼쪽에 고정된 사이드바(sticky) |
| < 1181px (태블릿·모바일) | **접힘(closed)** | 화면 밖에 숨겨진 드로어. 타이틀바의 목차 버튼으로 연다 |

두 경우 모두 타이틀바의 목차 토글 버튼(☰)으로 **수동으로 접고 펼 수 있다** —
데스크톱에서도 읽기 폭을 넓히고 싶으면 접을 수 있고, 모바일에서도 필요할 때
열 수 있다. 상태는 `<html data-toc="open|closed">` 속성 하나로 제어된다.

### 지켜야 할 것

- 섹션은 반드시 `<section>` 태그 + 그 안의 첫 `<h2>`로 만든다. `<div class="fake-section">`
  같은 변형을 쓰면 목차에 잡히지 않는다.
- `id`를 수동으로 넣고 싶다면(예: 외부 링크용 고정 URL) `<section id="원하는-id">`처럼
  직접 지정해도 된다 — 스크립트는 **이미 있는 id는 덮어쓰지 않는다.**
- `#tocPanel`, `#tocList`, `#tocBackdrop`, `.toc-btn`, `.toc-close` — 이 id/클래스
  이름은 스크립트가 직접 참조한다. 이름을 바꾸면 목차가 통째로 동작하지 않는다.
- `.desktop > .layout > (aside#tocPanel, .window)` 구조를 유지한다. `.layout`
  래퍼를 제거하고 `.window`를 `.desktop`의 직계 자식으로 되돌리면 데스크톱
  사이드바 레이아웃이 깨진다.

## 2. 코드 복사 버튼

### 동작 방식

같은 스크립트가 문서의 `.termwin` 블록을 전부 찾아서, 각 `.termbar`(트래픽
라이트가 있는 헤더) 오른쪽 끝에 "복사" 버튼을 자동으로 붙인다. `references/components.md`의
`termwin` 마크업을 그대로 쓰면 별도 작업 없이 버튼이 생긴다.

클릭하면 `pre.term`의 텍스트(주석·명령어 등 안의 `<span>` 태그는 제거되고 순수
텍스트만) 를 클립보드에 복사하고, 1.6초간 "복사됨"으로 바뀐다.

### file:// 에서도 동작하는 이유

로컬 `.html`을 더블클릭해서 여는 `file://` 프로토콜은 브라우저가 "보안 컨텍스트"로
취급하지 않는 경우가 많아, 최신 `navigator.clipboard.writeText()` API가 막힐 수
있다. 그래서 이 스크립트는:

1. 먼저 `navigator.clipboard.writeText()`를 시도하고,
2. 실패하거나 API가 없으면 숨김 `<textarea>` + `document.execCommand('copy')`
   구식 방식으로 자동 대체한다.

즉 Artifact로 게시(https, 보안 컨텍스트)해도, 로컬 파일로 저장해서 열어도
복사 버튼이 똑같이 동작한다.

### 지켜야 할 것

- 코드블록은 반드시 `references/components.md`의 `.termwin > .termbar > pre.term`
  구조를 그대로 쓴다. 이 구조를 벗어난 `<pre>`/`<code>` 블록에는 버튼이 붙지 않는다.
- 인라인 코드(`<code>…</code>` 한 단어짜리)에는 버튼을 달지 않는다 — 원래 그 용도가
  아니다. 여러 줄 명령/코드만 `termwin`으로 감싼다.

## 커스터마이징

- 데스크톱 기본 펼침 폭(1181px)을 바꾸려면 `assets/template.html`의
  `@media (min-width:1181px)` 두 곳(CSS)과 JS의 `matchMedia('(min-width:1181px)')`
  값을 **함께** 바꾼다. 하나만 바꾸면 레이아웃과 기본 열림/닫힘 판정이 어긋난다.
- 사이드바 폭(기본 258px)은 CSS의 `.toc-panel{width:258px;flex:0 0 258px}`
  (데스크톱 미디어쿼리 안)만 바꾸면 된다.
