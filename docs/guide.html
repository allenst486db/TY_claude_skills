TY_claude_skills — 스킬 동기화 가이드

Claude Code · Skills Sync Guide

여러 PC에서 스킬을 하나의 리포로 관리하기

각 PC의 ~/.claude/skills 디렉토리를 이 리포의 작업본(clone)으로 맞추면, 어디서든 pull로 받고 push로 올리며 동일한 스킬을 씁니다.

1

Concept

동기화 구조 한눈에 보기

중앙의 GitHub 리포가 단일 원본이고, 각 PC는 그 사본입니다. 스킬을 고치면 push로 원본에 반영하고, 다른 PC는 pull로 따라옵니다.

2

Setup

새 PC에서 처음 설치

경우 A
~/.claude/skills 가 없거나 비어 있음 → 바로 clone
경우 B
그 PC에 이미 로컬 스킬이 있음 → 3번 편입 절차
경우 A

비어 있는 경우 — clone

가장 간단

리포를 스킬 디렉토리 위치로 그대로 내려받습니다.

새 PC 설치 — Terminal
# macOS / Linux
git clone https://github.com/allenst486db/TY_claude_skills.git ~/.claude/skills

# Windows (PowerShell)
git clone https://github.com/allenst486db/TY_claude_skills.git "$env:USERPROFILE\.claude\skills"
설치 후

Claude Code를 새 세션으로 시작해야 스킬이 로드됩니다.

3

Contribute

다른 PC의 기존 스킬을 리포에 편입

이미 로컬 스킬이 있는 PC를 리포와 합칩니다. 서로 다른 이름의 스킬 폴더는 충돌 없이 그대로 합쳐집니다.

~/.claude/skills — Terminal
# 스킬 디렉토리로 이동  (Windows: cd "$env:USERPROFILE\.claude\skills")
cd ~/.claude/skills

# 1) git 저장소로 초기화하고 로컬 스킬을 먼저 커밋
git init -b main
git add -A
git commit -m "local skills from <이-PC-이름>"

# 2) 원격 연결 후 내려받아 병합 (서로 다른 뿌리이므로 옵션 필요)
git remote add origin https://github.com/allenst486db/TY_claude_skills.git
git fetch origin
git merge origin/main --allow-unrelated-histories -m "merge TY_claude_skills"

# 3) 합쳐진 결과를 올림
git push -u origin main
충돌이 나는 경우

두 PC가 같은 이름의 스킬을 서로 다른 내용으로 가지고 있으면 merge가 해당 파일에서 충돌을 표시합니다. 파일을 열어 남길 내용을 정리한 뒤 git add <파일> → git commit → git push로 마무리합니다.

대안 — 병합이 번거로울 때

리포를 임시 폴더에 clone → 올릴 스킬 폴더만 복사 → commit/push 해도 됩니다. 단, 이 방식은 그 PC의 ~/.claude/skills를 리포 작업본으로 만들지는 않습니다.

임시 clone — Terminal
git clone https://github.com/allenst486db/TY_claude_skills.git /tmp/ty_skills
cp -r ~/.claude/skills/<올릴-스킬> /tmp/ty_skills/
cd /tmp/ty_skills && git add -A && git commit -m "add <올릴-스킬>" && git push
4

Daily

평상시 관리 루프

작업 시작 전 pull, 끝나고 push를 습관화하면 PC 간 충돌이 거의 없습니다.

평상시 관리 — Terminal
cd ~/.claude/skills

git pull                    # 다른 PC에서 올린 최신 스킬 받기
# … 스킬 수정 또는 새로 만든 뒤 …
git add -A
git commit -m "update: <내용>"
git push

✓
폴더명 = 스킬명 — SKILL.md의 name과 폴더 이름을 같게 맞춥니다.
✓
description에 "언제 쓰는지" — 발동 조건을 구체적으로 적어야 스킬이 잘 트리거됩니다.
✓
push 전 pull — 올리기 전 최신 상태를 받아 충돌을 예방합니다.
