Claude Code 스킬 스택 설치 가이드

스킬 1종 · 플러그인 4종 · MCP 서버 2종을 전역(user) 스코프에 설치한 기록입니다. 무엇을 왜 그렇게 설치했는지, 남은 수동 단계가 무엇인지, 새 PC에서 어떻게 똑같이 재현하는지를 정리했습니다.

1

Overview

설치 구조 — 전부 한곳으로 모인다

설치 경로는 세 갈래지만 도착지는 하나입니다. 모두 전역 ~/.claude에 들어가므로, 이 저장소를 포함한 모든 프로젝트에서 별도 설정 없이 쓸 수 있습니다.

2

Research

deep-research — 인용이 붙는 리서치 파이프라인

여러 소스를 교차 검증하고, 근거를 파일로 남기고, 인용이 달린 리포트를 만듭니다. 검색 한두 번으로 끝나는 질문에는 스킬 스스로 거절하도록 설계돼 있습니다.

~/.claude/skills — Terminal
# 설치 — 스킬 디렉터리로 직접 clone
git clone --depth 1 https://github.com/199-biotechnologies/claude-deep-research-skill.git \
  ~/.claude/skills/deep-research

호출 방법

예시 1
deep research on 2026년 국내 전기차 보조금 정책 변화
예시 2
deep research in ultradeep mode: Postgres vs. ClickHouse 분석 워크로드 비교
quick · 3단계
2–5분 · 초기 탐색
standard · 6단계
10–20분 · 일반 리서치
deep · 8단계
30분+ · 의사결정용
ultradeep · 8+
정밀 비교 · 검증
  • 리포트는 ~/Documents/[주제]_Research_[날짜]/에 Markdown · HTML · PDF로 저장
  • 필수 의존성 — Python 3.9+ (표준 라이브러리만, pip install 불필요)
  • 선택 — weasyprint(PDF 출력), search-cli(검색 제공자 집계, API 키 필요)
적용하지 않은 선택 설정

업스트림 문서는 권한 프롬프트를 줄이려고 ~/.claude/settings.json의 permissions.allow에 WebSearch · WebFetch · Glob · Grep · Read를 넣으라고 권합니다.

이번에는 넣지 않았습니다. WebFetch 자동 승인은 임의 URL 접근을 확인 없이 허용하는 항목이라 판단이 필요합니다. 없어도 deep-research는 정상 동작하고, 확인창이 몇 번 더 뜰 뿐입니다.

Code Discipline

karpathy-guidelines — 코딩 실수 줄이기

Andrej Karpathy가 지적한 LLM 코딩의 전형적 실패 패턴을 규칙으로 만든 스킬입니다. 코드를 쓰거나 리뷰·리팩터링할 때 자동으로 걸립니다.

plugin install — Terminal
claude plugin marketplace add forrestchang/andrej-karpathy-skills
claude plugin install andrej-karpathy-skills@karpathy-skills

4대 원칙

  • Think Before Coding — 가정을 명시하고, 해석이 여러 개면 다 꺼내놓고, 모르면 멈추고 묻는다
  • Simplicity First — 요청된 것만. 1회용 코드에 추상화 금지, 불가능한 예외의 에러 처리 금지
  • Surgical Changes — 건드려야 할 것만. 옆 코드 "개선"·포맷 정리 금지
  • Goal-Driven Execution — 검증 가능한 성공 기준을 먼저 정의한다
트레이드오프

속도보다 신중함 쪽으로 기울어 있습니다. 사소한 작업에서는 다소 답답할 수 있습니다.

4

Token Compression

caveman — 출력 토큰 압축 (기본 OFF)

관사·군말·인사말·완충 표현을 걷어내고 문장 조각으로 답해 출력 토큰을 약 65% 절감합니다. 코드·명령어·에러 메시지는 건드리지 않습니다.

설치 기본값의 함정

기본 설치 상태에서는 SessionStart 훅이 모든 세션 첫 메시지부터 caveman 말투를 강제합니다. 일상 작업 가독성을 해치므로 이번에는 꺼둔 상태로 설정했습니다.

끄기 위해 만든 파일은 %APPDATA%\caveman\config.json 하나입니다.

%APPDATA%\caveman\config.json
{
  "defaultMode": "off"
}
명령설명
/caveman [lite·full·ultra·wenyan]압축 강도 전환
/caveman-commit50자 이하 컨벤셔널 커밋 메시지
/caveman-review한 줄짜리 PR 코멘트
/caveman-stats세션 · 누적 토큰 절감량
/caveman-compress <file>CLAUDE.md 등 메모리 파일 압축 (입력 토큰 ~46% 절감)
모드 우선순위

CAVEMAN_DEFAULT_MODE 환경변수 → 저장소별 .caveman/config.json → 사용자 설정 → 기본값(full). 특정 프로젝트에서만 항상 켜고 싶으면 그 저장소에 .caveman.json을 두면 됩니다.

Continuity

handoff — 세션 간 인수인계

컨텍스트가 압축되거나 세션이 끊겨도 다음 세션이 이어서 작업할 수 있게 상태를 파일로 남깁니다.

plugin install — Terminal
claude plugin marketplace add thepushkarp/handoff
claude plugin install handoff@handoff
명령동작
/handoff:create작업 상태 · 결정 · 수정 파일 · 막힌 지점 · 다음 단계를 docs/handoff/HANDOFF.md에 기록
/handoff:resume기록을 읽어 컨텍스트 복원
/handoff:resume --auto복원 후 곧바로 작업 재개
  • 컨텍스트 압축 직전에 스냅샷을 남기고, 압축 후 다시 주입하는 훅이 포함
  • jq가 있으면 더 자세히 기록하지만 없어도 동작합니다

Orchestration

Ruflo — MCP 등록만, init 은 실행하지 않음

구 Claude Flow. 100여 개 전문 에이전트, 스웜 실행, 공유 메모리, 210여 개 MCP 도구를 제공합니다. 문제는 설치 방식에 따라 기존 파일이 날아간다는 점입니다.

적용한 명령 — Terminal
claude mcp add ruflo --scope user -- npx -y ruflo@latest mcp start

init 이 꼭 필요해지면

빈 하위 폴더에서만 — Terminal
# 반드시 비어 있는 폴더에서
mkdir ruflo-workspace && cd ruflo-workspace
npx ruflo@latest init wizard

검증 결과

  • npm 버전 3.32.9 확인
  • MCP initialize 핸드셰이크 1.8초 내 정상 응답 (serverInfo.name = "ruflo")
  • claude mcp list → 연결 성공
  • 첫 등록 직후 한 번 실패할 수 있음 — npx가 패키지를 처음 내려받는 시간 때문이며, 캐시된 뒤 재실행하면 정상입니다

Knowledge Base

NotebookLM — 인증 한 단계 남음

내 NotebookLM 노트북에 근거해서 인용이 붙은 답변을 받습니다. 소스 추가와 오디오(팟캐스트) 생성도 가능합니다.

적용한 명령 — Terminal
claude mcp add notebooklm --scope user -- npx -y notebooklm-mcp@latest
남은 수동 단계

설치 세션은 비대화형이라 OAuth를 진행할 수 없었습니다. 대화형 claude 세션에서 NotebookLM setup_auth 도구 실행을 요청하면 Chrome 창이 열립니다. Google 계정으로 로그인하면 쿠키가 사용자별 Chrome 프로필에 저장됩니다.

문제가 생기면 re_auth(초기화 후 재인증) 또는 cleanup_data(전체 초기화)를 씁니다.

주요 도구

  • 질의 — ask_question (인용 추출 옵션)
  • 소스 — add_source(URL·텍스트), generate_audio, download_audio
  • 라이브러리 — add_notebook, list_notebooks, search_notebooks

요구사항

  • Node 18+ · Chrome 안정 채널 권장 (번들 Chromium 대체 가능)
  • WSL1 불가 — Chromium 실행이 안 됩니다. WSL2 + WSLg 필요
  • 여러 계정은 --account 플래그로 분리

Reproduce · Remove

새 PC에서 그대로 재현하기

설치 스크립트는 멱등이라 여러 번 돌려도 안전하고, 이미 있는 항목은 건너뜁니다.

새 PC 세팅 — Terminal
git clone <이 저장소> && cd <저장소>

# Windows
pwsh -File scripts/install-claude-skills.ps1

# macOS / Linux / Git Bash
bash scripts/install-claude-skills.sh
✓
스크립트 실행 완료 — 마켓플레이스 · 플러그인 · 스킬 · MCP 서버가 모두 등록됐는지 출력으로 확인.
✓
NotebookLM 인증 — 대화형 세션에서 setup_auth 실행 (8절 참고).
✓
Claude Code 재시작 — 새 스킬·플러그인은 재시작해야 로드됩니다.
✓
caveman 기본값 확인 — %APPDATA%\caveman\config.json이 이미 있으면 스크립트가 건너뛰므로 defaultMode를 직접 확인.

제거

uninstall — Terminal
# 플러그인
claude plugin uninstall caveman@caveman
claude plugin uninstall handoff@handoff
claude plugin uninstall andrej-karpathy-skills@karpathy-skills

# 마켓플레이스 등록 해제
claude plugin marketplace remove caveman

# MCP 서버
claude mcp remove ruflo --scope user
claude mcp remove notebooklm --scope user

deep-research 스킬은 ~/.claude/skills/deep-research 폴더를 지우면 됩니다.
